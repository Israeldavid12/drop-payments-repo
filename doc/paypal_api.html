Documentação da API - Sistema de Pagamentos

Consulte os detalhes sobre como interagir com a API para consultar saldo, processar pagamentos, etc.

1. /api/paypal-success

Descrição: Endpoint chamado quando o pagamento é bem-sucedido no PayPal.

Método: GET

Parâmetros:

  • PayerID: ID do pagador fornecido pelo PayPal
  • paymentId: ID do pagamento fornecido pelo PayPal
  • clientId: ID do usuário que realizou o pagamento

Exemplo de Requisição:

GET /api/paypal-success?PayerID=12345&paymentId=abc123&clientId=user123

Resposta de Sucesso:

{
  "message": "Pagamento processado e saldo atualizado com sucesso!"
}

Resposta de Erro:

{
  "message": "Erro ao processar pagamento"
}

2. /api/paypal-cancel

Descrição: Endpoint chamado quando o pagamento é cancelado pelo usuário no PayPal.

Método: GET

Parâmetros:

  • cancelPage: URL para redirecionar o usuário após o cancelamento

Exemplo de Requisição:

GET /api/paypal-cancel?cancelPage=https://your-domain.com/cancel

Resposta de Sucesso:

{
  "message": "Pagamento foi cancelado pelo usuário."
}

3. /api/check-balance

Descrição: Endpoint para consultar o saldo de um usuário.

Método: GET

Parâmetros:

  • clientId: ID do usuário

Exemplo de Requisição:

GET /api/check-balance?clientId=user123

Resposta de Sucesso:

{
  "balance": 100.00
}

Resposta de Erro:

{
  "message": "Usuário não encontrado"
}
